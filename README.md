# Project Title
An attempt at making an auto-solver for [Dr. Kobushi's Labyrinthine Laboratory](https://store.steampowered.com/app/1829450/Dr_Kobushis_Labyrinthine_Laboratory/).

## Prerequisites
Unfortunately, as this is a hobby project not intended for anyone else's use (for now),
This program is intended for the Windows OS and may never be compatible with other
operating systems unless other contributors want to join in.
I cannot help anyone who does not meet the prerequisites listed below.
- **Primary IDE:** Visual Studio (but any IDE that can run CMake will do)
- **Primary compiler:** Microsoft Visual C++ (MSVC)
- **Primary OS:** Windows (not yet tested on other OS's)

## Setup (Visual Studio)
1. Clone the repo or download the zip file.
2. Open Visual Studio.
3. "Open Local Folder"
4. Navigate to the location of the repo or extracted zip file.
5. The IDE should detect `CMakeLists.txt` and set it up for you. Make sure to open the Output Window and check if building was successful. If not, feel free to send us an issue.

## Sending An Issue
If you encounter any bugs or have feature requests, please open an issue on the [GitHub repository](https://github.com/yamaken81/KobushiSolver/issues).

### Format
Make sure to include the following information:
- Proper headers for each section of the issue. Try to use `###` for any text presented in **bold** below.
- **Description**: A clear and concise description of what the bug is or what feature you are requesting.
- **Steps to Reproduce**: If reporting a bug, how did you get it? Try to list the steps
needed to reproduce. If none of the contributors can reproduce it, it will be hard to fix.
